# Effect

`class`

Import from `game/prototypes/game-object`.

Represents an effect applied to a game object.

- **Effect** — Description
- **`EFF_ATTACK_MODIFIER`** — Modifies outgoing damage dealt when a creep uses `attack` with an `ATTACK` body part using the effect's multiplier and offset.
- **`EFF_RANGED_ATTACK_MODIFIER`** — Modifies outgoing damage dealt by `rangedAttack` or `rangedMassAttack` using the effect's multiplier and offset. For mass attacks, the modifier is applied separately to the base damage calculated for each target.
- **`EFF_HEAL_MODIFIER`** — Modifies healing produced by `heal` or `rangedHeal` using the effect's multiplier and offset.
- **`EFF_DAMAGE_TAKEN_MODIFIER`** — Modifies incoming combat damage dealt by creeps using the effect's multiplier and offset: damage from `attack` using `ATTACK`, and damage from `rangedAttack` or `rangedMassAttack` using `RANGED_ATTACK`. Other damage sources are not modified.
- **`EFF_FATIGUE_MODIFIER`** — Modifies positive fatigue generated by each movement event using the effect's multiplier and offset. It does not change fatigue recovery provided by `MOVE` body parts.
- **`EFF_HITS_LOSS`** — Changes the affected object's hits by the effect's negative `offset` once per tick. This is not combat damage: it is not modified by `EFF_DAMAGE_TAKEN_MODIFIER` and does not create a combat action log. Death and creep body state are processed by the standard damage pipeline.
- **`EFF_CONSTRUCTION_BOOST`** — **Deprecated.** Multiplies construction progress produced by `build`. The multiplier is applied after energy consumption is calculated, so it changes progress without changing the energy cost.
- **`EFF_ATTACK_BOOST`** — **Deprecated.** Multiplies outgoing damage dealt by `attack`.
- **`EFF_RANGED_ATTACK_BOOST`** — **Deprecated.** Multiplies outgoing damage dealt by `rangedAttack` and `rangedMassAttack`.
- **`EFF_HEAL_BOOST`** — **Deprecated.** Multiplies healing produced by `heal` and `rangedHeal`.
- **`EFF_WORK_BOOST`** — **Deprecated.** Multiplies energy harvested by `harvest` and the build power, including energy consumption, used by `build`.
- **`EFF_MOVE_BOOST`** — **Deprecated.** Multiplies fatigue recovery provided by `MOVE` body parts. It does not change fatigue generated by movement.

### data

**Type:** `{ multiplier?: number; offset?: number }`

The values used to apply the effect. Missing `multiplier` and `offset` values default to 1 and 0, respectively.

Modifier effects calculate the modified value as `result = base * (multiplier ?? 1) + (offset ?? 0)`. The multiplier is applied first, then the offset.

### effectType

**Type:** `string`

The effect type.

### endTime

**Type:** `number | undefined`

The game tick when the effect expires. The effect is active while the current tick is less than this value. It may be omitted from effect templates that are not currently applied to a game object.
